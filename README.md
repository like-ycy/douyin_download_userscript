# 抖音画质探测与下载

在抖音网页版点击下载图标，自动获取**当前正在看的视频**的画质、实际分辨率和文件大小，再选择版本下载。

当前版本：**0.1.6**。适用于桌面 Chrome / Edge 与 Tampermonkey（油猴），无需 Python、独立浏览器或后台服务。

## 功能

- 在推荐、关注和视频详情页识别当前作品，点击图标后才开始探测。
- 展示 `default` 播放档和网页提供的其他版本，读取实际文件大小，合并重复直链。
- 下载图标可拖动，刷新或重新打开页面后记住位置，窗口变小时保持在可见区域。
- 自动生成「作者 - 标题 - 画质.mp4」文件名，清理非法符号、控制字符与 Windows 保留名称。
- 完整文件名最多 120 个 UTF-16 单元、200 个 UTF-8 字节，包含画质后缀及扩展名；截断时保留完整 emoji 和组合字符。
- 支持停止探测、取消下载；切换作品时取消旧探测，已开始的下载保持原作品。

## 安装

1. 在浏览器安装 Tampermonkey，并在扩展管理页开启「允许运行用户脚本」。旧版浏览器可能需要开启扩展的「开发者模式」。
2. 打开 [douyin-quality-downloader.user.js](douyin-quality-downloader.user.js)，复制全部代码，包含最上方的 `// ==UserScript==` 声明。
3. 在油猴中选择「新建脚本」，替换全部内容并按 **Ctrl+S / ⌘S** 保存。更新旧版时，编辑原来的同名脚本即可。
4. 刷新 [抖音网页版](https://www.douyin.com/)，使用网页已有的登录状态。

## 使用

播放视频后，点击画面旁的下载图标，自动识别并探测当前作品。从结果表格选择一行点击「下载」。按住图标拖动可调整位置，松手自动保存。

首次请求视频服务器时，如果油猴询问跨域权限，允许访问脚本声明的视频域名。

如果下载功能尚未开启，在油猴设置中将「配置模式」设为「高级」，找到「下载模式」，选择「浏览器 API」并保存，按提示授予下载权限。如果提示文件类型不允许，将 `.mp4` 加入允许的扩展名。

「浏览器 API」模式先通过油猴取回视频，再交给浏览器保存，因此需要内存暂存完整文件。「原生」模式的完成提示表示已交给浏览器保存，请以浏览器下载列表为准。下载目录由浏览器设置决定；文件名限制不涵盖用户选择的完整目录路径长度。

## 画质与大小

| 显示 | 含义 |
| --- | --- |
| `default · 原始播放档` | 使用 `ratio=default` 播放接口，单独置顶；不承诺所有作品都返回上传前未经处理的原文件。 |
| 播放档 | 移动端播放接口返回的文件。请求的 `4k` 可能返回较低画质，因此不会直接用请求参数当作实际分辨率。 |
| 网页画质 | 网页详情中的其他版本，可能包含不同码率和 H.264 / H.265 编码；H.265 需要播放器支持。 |
| 真实大小 | 从 CDN 的 `Content-Range` 等响应头读取，缺失时显示「大小未知」。 |

探测大小通常只读取一个字节；读取实际分辨率时最多额外读取两段各 256 KiB 的 MP4 索引。CDN 忽略 Range 请求时停止读取并报错。

## 常见问题

- **保存后图标还是旧的**：确认油猴中的已安装版本为 `0.1.6`，并刷新抖音页面。仅粘贴代码而没有保存不会生效。
- **首屏或某条视频没有识别出来**：脚本同时读取页面内嵌的 RSC 数据和后续网络响应；当前卡片由 `data-e2e-vid` 标识。点击后最多等待 10 秒，仍失败时刷新页面重试。
- **某些画质失败**：展开「查看未成功的探测」。CDN 可能拒绝部分版本，已成功的版本仍可以下载。
- **下载地址过期**：刷新页面并重新探测。移动端档位下载前会重新获取签名地址。
- **复制了分享短链接才可以下载吗**：不需要。在推荐、关注页直接点击图标即可，地址栏不变或播放器使用 `blob:` 也支持。

当前支持普通视频。图文、直播、加密内容不在支持范围内；Safari、手机浏览器和其他脚本管理器尚未验证。抖音页面或接口变更后可能需要更新脚本。
