# 抖音画质探测与下载

[![Greasy Fork](https://img.shields.io/badge/Greasy%20Fork-安装脚本-red)](https://greasyfork.org/zh-CN/scripts/600007-%E6%8A%96%E9%9F%B3%E7%94%BB%E8%B4%A8%E6%8E%A2%E6%B5%8B%E4%B8%8E%E4%B8%8B%E8%BD%BD) [![GitHub](https://img.shields.io/badge/GitHub-源码仓库-181717?logo=github)](https://github.com/like-ycy/douyin_download_userscript) [![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

在抖音网页版点击下载图标，自动识别**当前正在看的视频或图集**：视频可选择画质下载，图集可逐张或整组保存。

当前版本：**0.3.0**。适用于桌面 Chrome / Edge 与 Tampermonkey（油猴），无需 Python、独立浏览器或后台服务。

源码仓库：<https://github.com/like-ycy/douyin_download_userscript> —— 欢迎 Star；想修改或二次开发请直接打开该地址，问题反馈可提交 [Issue](https://github.com/like-ycy/douyin_download_userscript/issues)。

## 功能

- 在推荐、关注和视频详情页识别当前作品，点击图标后才开始探测。
- 展示 `default` 播放档和网页提供的其他版本，读取实际文件大小，合并重复直链。
- 图集展示图片顺序、尺寸、格式和文件大小，支持单张下载或按顺序下载全部图片；优先使用页面提供的 JPEG 地址。
- 图集可一键打包为 ZIP 压缩包保存：包内文件名与逐张下载一致，下载与打包全程显示进度条，打包阶段显示动态条纹提示，随时可取消。
- 下载图标可拖动，刷新或重新打开页面后记住位置，窗口变小时保持在可见区域。
- 探测面板跟随下载图标弹出：图标在上半屏时向下展开、下半屏时向上展开，拖动图标时面板实时跟随；再次点击图标即可收起。
- 自动生成「作者 - 标题 - 画质.mp4」文件名，清理非法符号、控制字符与 Windows 保留名称。
- 图集文件名为「作者 - 标题 - 图片001.jpg」等，扩展名按实际图片格式生成，保留原图集顺序。
- 完整文件名最多 120 个 UTF-16 单元、200 个 UTF-8 字节，包含画质后缀及扩展名；截断时保留完整 emoji 和组合字符。
- 支持停止探测、取消下载；切换作品时取消旧探测，已开始的下载保持原作品。

## 安装

1. 在浏览器安装 Tampermonkey，并在扩展管理页开启「允许运行用户脚本」。旧版浏览器可能需要开启扩展的「开发者模式」。
2. 打开 [Greasy Fork 发布页](https://greasyfork.org/zh-CN/scripts/600007-%E6%8A%96%E9%9F%B3%E7%94%BB%E8%B4%A8%E6%8E%A2%E6%B5%8B%E4%B8%8E%E4%B8%8B%E8%BD%BD)，点击「安装此脚本」，油猴会自动完成安装，后续更新也会自动检查。
3. 刷新 [抖音网页版](https://www.douyin.com/)，使用网页已有的登录状态。

## 使用

播放视频后，点击画面旁的下载图标，自动识别并探测当前作品，面板在图标旁弹出（见上方视频下载示例）。从结果表格选择一行点击「下载」，再次点击图标可收起面板。按住图标拖动可调整位置，面板会跟着移动，松手自动保存。

查看图集时，点击同一个下载图标即可列出全部图片，无需翻动图片或进入详情页。可逐张下载、点击「下载全部图片」顺序保存为独立文件，或点击「下载为 ZIP」打包成一个压缩包（图片多时更省事）。部分图片探测失败时会显示原因，并可下载已识别的图片。图片尺寸来自作品数据，保存的是网页提供的图片版本，不保证是上传原文件；Live Photo 仅保存静态图片。

整组下载可以取消，已保存的图片会保留；途中失败会停止后续下载并提示已完成数量，可单独重试剩余图片。切换作品不会改变已经开始的下载队列。

首次请求媒体服务器时，如果油猴询问跨域权限，允许访问脚本声明的域名；图集新增使用 `douyinpic.com`。

如果下载功能尚未开启，在油猴设置中将「配置模式」设为「高级」，找到「下载模式」，选择「浏览器 API」并保存，按提示授予下载权限。如果提示文件类型不允许，将 `.mp4`、`.zip` 以及需要的图片扩展名（`.jpg`、`.png`、`.webp`、`.gif`、`.avif`）加入允许列表。

「浏览器 API」模式先通过油猴取回文件，再交给浏览器保存，因此需要内存暂存完整文件；图集一次只处理一张图片。「原生」模式的完成提示表示已交给浏览器保存，请以浏览器下载列表为准。下载目录由浏览器设置决定；文件名限制不涵盖用户选择的完整目录路径长度。

## 画质与大小

| 显示 | 含义 |
| --- | --- |
| `default · 原始播放档` | 使用 `ratio=default` 播放接口，单独置顶；**就是该作品的最高画质**（原始上传播放档），追求画质直接选它即可。 |
| 播放档 | 移动端播放接口返回的文件。请求的 `4k` 可能返回较低画质，因此不会直接用请求参数当作实际分辨率。 |
| 网页画质 | 网页详情中的其他版本，可能包含不同码率和 H.264 / H.265 编码；H.265 需要播放器支持。 |
| 真实大小 | 从 CDN 的 `Content-Range` 等响应头读取，缺失时显示「大小未知」。 |

探测大小通常只读取一个字节；读取实际分辨率时最多额外读取两段各 256 KiB 的 MP4 索引。CDN 忽略 Range 请求时停止读取并报错。

## 常见问题

- **保存后图标还是旧的**：确认油猴中的已安装版本为 `0.2.0`，并刷新抖音页面。通过 Greasy Fork 安装时，等待油猴自动更新或在其页面手动点击更新。
- **首屏或某条作品没有识别出来**：脚本读取页面内嵌的 RSC 数据和后续网络响应，点击时也会读取当前卡片的组件数据；当前卡片由 `data-e2e-vid` 标识。点击后最多等待 10 秒，仍失败时刷新页面重试。
- **某些画质失败**：展开「查看未成功的探测」。CDN 可能拒绝部分版本，已成功的版本仍可以下载。
- **下载地址过期**：刷新页面并重新探测。移动端档位下载前会重新获取签名地址。
- **复制了分享短链接才可以下载吗**：不需要。在推荐、关注页直接点击图标即可，地址栏不变或播放器使用 `blob:` 也支持。

当前支持普通视频和图片图集。直播、加密内容及 Live Photo 动态部分不在支持范围内；Safari、手机浏览器和其他脚本管理器尚未验证。抖音页面或接口变更后可能需要更新脚本。

- **不建议下载时长较长的视频**：本脚本主要用于自用，针对**一分钟内**的短视频设计；更长的视频尚未做过测试，可能无法正常下载或保存。

## 文件与发布

本仓库只包含独立用户脚本和文档，无需安装依赖或构建。登录由抖音页面完成，脚本不导出或保存登录 Cookie；油猴存储仅用于图标位置。
